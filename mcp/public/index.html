taipei-trash MCP server

Read-only Model Context Protocol server for garbage-truck stops and arrival times in Taipei, New Taipei, Taichung and Kaohsiung. No authentication; times are Asia/Taipei.

Connect

Endpoint (Streamable HTTP): https://mcp.garbage.yukai.dev/mcp

{ "mcpServers": { "taipei-trash": { "url": "https://mcp.garbage.yukai.dev/mcp" } } }

Stdio-only clients: npx mcp-remote https://mcp.garbage.yukai.dev/mcp

Tools

list_citiesSupported cities, ids and bounding boxes
find_nearby_pointsStops near a coordinate, nearest first
search_pointsSearch a city's stops by district / village / road / route
get_scheduleA stop and every stop on its route in arrival order
