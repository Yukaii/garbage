Taiwan Garbage Truck Map · MCP Server

Read-only Model Context Protocol server for querying garbage and recycling truck stops, routes, and arrival times in Taipei, New Taipei, Taichung, and Kaohsiung. No API key or authentication required. All times are in Asia/Taipei.

Connect

Streamable HTTP endpoint: https://mcp.garbage.yukai.dev/mcp

{
  "mcpServers": {
    "taipei-trash": {
      "url": "https://mcp.garbage.yukai.dev/mcp"
    }
  }
}

For stdio-only clients: npx mcp-remote https://mcp.garbage.yukai.dev/mcp

Available Tools

list_citiesList supported cities, their IDs, and geographic bounding boxes
find_nearby_pointsFind collection stops within 50–2,000 m of a coordinate, ordered nearest first
search_pointsSearch stops within a city by district, village, road, or route name
get_scheduleGet details for a stop along with the full stop sequence of its route
